# Test Forge

A hands-on REST API testing, BDD/Gherkin, and SQL practice project — built from first principles, with every example grounded in real API traffic rather than toy examples.

## What this covers

- **REST API testing** — Playwright's `request` context (TypeScript), covering HTTP methods, status codes, schema validation, request chaining, and negative testing, against a real telecom sales-quote API
- **BDD/Gherkin** — Cucumber + Playwright scenarios describing business rules in Given/When/Then form, combining API-driven test data setup with UI-facing checks
- **SQL** — a light SQLite practice piece (joins, aggregations, common interview-style queries) seeded with realistic captured data

## Why this exists

A learning-focused project — the goal is genuine, durable understanding of how each of these testing disciplines works and why it exists in the industry, not just interview-ready talking points.

## Status

Actively being built, section by section. Structure and setup instructions land here once the framework itself is in place.
